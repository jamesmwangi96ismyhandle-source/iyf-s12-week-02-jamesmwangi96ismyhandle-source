What Is Semantic HTML?

Semantic HTML uses elements that describe the meaning and purpose of the content they contain.

Examples of Semantic Elements

  • header: Introduces a page or section.
  • nav: Contains navigation links.
  • main: Holds the main content of the page.
  • article: Contains independent, meaningful content.
  • aside: Contains related supplementary information.
  • footer: Contains closing information.

Why Semantic HTML Matters

Semantic HTML improves accessibility, makes code easier to understand, and helps browsers and assistive technologies interpret the structure of a webpage.

Did You Know?

Using meaningful HTML elements helps screen-reader users navigate a webpage more easily.
