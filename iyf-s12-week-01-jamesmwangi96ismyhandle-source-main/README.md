# Week 1 Web Foundations Portfolio

## About This Project

This repository contains my Week 1 Web Foundations assignment
for IYF Season 12.

I built a multi-page personal portfolio using semantic HTML.
The project demonstrates webpage structure, navigation,
accessible forms, browser DevTools exploration, and accessibility
testing with Lighthouse.

## About Me

My name is James Mwangi. I am an agriculture teacher and a
football and handball coach with four years of teaching experience.

I am learning web development to build my technical skills and
create useful digital projects.

## Pages Included

- `index.html` — Home page and personal introduction.
- `about.html` — Background, experience, and skills.
- `projects.html` — Projects and proposed initiatives.
- `contact.html` — Contact form with labeled fields.
- `semantic-conversion.html` — Practice using semantic HTML.
- `devtools-exploration.md` — Notes from exploring browser DevTools.
- `accessibility-report.md` — Lighthouse accessibility testing results.

## Technologies Used

- HTML5
- Markdown
- Google Chrome Developer Tools
- Google Lighthouse
- Git and GitHub
- GitHub Pages

## Accessibility

I used semantic HTML elements and labels for form fields.
I also tested my website with Lighthouse and documented the
actual results in `accessibility-report.md`.
