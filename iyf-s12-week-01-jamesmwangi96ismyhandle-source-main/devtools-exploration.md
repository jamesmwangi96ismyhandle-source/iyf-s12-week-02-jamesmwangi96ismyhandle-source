
# Browser DevTools Exploration

## Introduction

Browser Developer Tools (DevTools) help web developers inspect,
test, debug, and improve websites.

I explored browser DevTools while working on my IYF Season 12
Week 1 Web Foundations portfolio.

## 1. Elements Panel

The Elements panel allows me to inspect the HTML structure of
a webpage.

### What I Explored

- Inspected HTML elements such as `header`, `nav`, `main`, and `footer`.
- Learned how to view the structure of a webpage.
- Learned how to temporarily edit HTML in the browser.
- Discovered that temporary changes do not automatically update
  my original files on GitHub.

## 2. Console Panel

The Console panel helps developers identify errors and warnings.

### What I Explored

- Opened the Console panel in browser DevTools.
- Learned that JavaScript errors and warnings can appear there.
- Learned how the Console can help troubleshoot webpage problems.

## 3. Network Panel

The Network panel shows the resources a webpage requests from
the browser.

### What I Explored

- Viewed files loaded by a webpage.
- Learned how to identify failed requests.
- Discovered that missing files can affect how a website works.

## 4. Device Toolbar

The Device Toolbar allows developers to preview webpages at
different screen sizes.

### What I Explored

- Tested how a webpage appears at different viewport widths.
- Learned why mobile-friendly design is important.
- Discovered that responsive testing can reveal layout problems.

## 5. What I Learned

Through exploring DevTools, I learned that developers can inspect
HTML, investigate errors, examine network requests, and test
webpages at different screen sizes.

These tools will help me find and fix problems as I continue
developing my personal portfolio.

## Conclusion

Browser DevTools are useful tools for testing and debugging
websites. I will continue using them to improve the structure,
functionality, and responsiveness of my portfolio.
